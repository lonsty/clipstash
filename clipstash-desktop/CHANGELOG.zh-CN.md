# 更新日志

本文档记录此项目的所有重要变更。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.2.1] - 2026-03-26

### 新增

- **CodeMirror 6 语法高亮** — 使用 CodeMirror 6 替代 highlight.js，支持 30 种语言，采用 GitHub 风格亮色/暗色配色方案
- **CM6 内联编辑器** — 弹窗和全屏编辑模式使用完整的 CodeMirror 6 编辑器，支持行号、括号匹配、代码折叠、撤销/重做、搜索
- **CM6 按需加载** — CM6 bundle（~1 MB）仅在首次使用时动态加载，保持应用启动即时响应
- **回收站自动清理** — 过期回收站项目（>30 天）在应用运行期间每小时自动清理

### 变更

- **图片同步逻辑** — "同步图片"开关仅控制上传；云端图片始终会被拉取，无论开关状态（Rust 后端已同步更新）
- **主题感知高亮** — 语法高亮在切换亮色/暗色主题时自动适配

### 移除

- **highlight.js** — 已被 CodeMirror 6 替代

## [0.2.0] - 2026-03-23

### 新增

- **云同步** — 通过 GitHub Gist 跨设备同步剪贴板数据；使用细粒度 PAT（Gists 读写权限）连接
- **同步加密** — 所有云端数据均使用 AES-256-GCM + gzip 压缩加密；用户可设置可选的同步密码以增强安全性
- **同步密码管理** — 支持设置、修改、移除同步加密密码，包含确认校验
- **自动同步** — 本地数据变更后自动推送（防抖），定时拉取远端更新（5 分钟间隔）；可在设置中开关
- **快速同步按钮** — 顶栏快捷按钮，一键手动同步，带状态指示（同步中 / 已连接 / 错误）
- **图片云同步** — 可选同步图片类剪贴板内容到 Gist，支持单张（5 MB）和总量（50 MB）配额限制
- **强制推送** — 同步密码不匹配时提供强制推送选项，用本地数据覆盖云端数据
- **跨设备去重** — 基于内容哈希（SHA-256）的去重机制，防止同步时产生跨设备重复记录
- **回收站** — 软删除，保留 30 天；支持恢复或永久删除；显示剩余天数倒计时
- **回收站批量操作** — "全部恢复"和"清空回收站"按钮
- **永久删除全部数据** — 设置中的危险操作，可永久清除所有数据（活跃 + 回收站）
- **共享模块** — 提取 `shared/` 目录，包含 `constants.js`、`messages.js`、`icons.js`、`dom-utils.js`、`fullscreen-controller.js`、`crypto.js`，供扩展和桌面端共用
- **模块化架构** — `main.js` 拆分为独立模块：`card-renderer.js`、`modal-controller.js`、`trash-panel.js`、`sync-ui.js`、`settings-panel.js`
- **自适应时间刷新** — 卡片相对时间和同步"上次同步"时间根据数据年龄以自适应间隔自动刷新
- **同步 Rust 后端** — 新增 `sync.rs` 和 `crypto.rs` 模块，在 Rust 层实现 GitHub Gist 同步、AES-256-GCM 加密和 gzip 压缩

### 变更

- **国际化架构** — 共享 `BASE_MESSAGES` + 平台特定 `DESKTOP_MESSAGES`；`mergeMessages()` 函数实现组合式翻译
- **时间格式化** — 委托给共享 `dom-utils.js`，通过依赖注入 `t()` 函数
- **代码组织** — `main.js` 从约 1200 行缩减至约 400 行；`fullscreen.js` 和 `sticky.js` 使用共享 `fullscreen-controller.js`
- **数据库模式** — 新增 `deleted_at` 和 `content_hash` 列、`sync_meta` 表及回收站相关查询
- **存储层** — 新增回收站操作（`soft_delete`、`restore`、`purge_expired`、`get_deleted`）、同步数据转换及待删除/待恢复追踪
- **Rust 依赖** — 新增 `reqwest`、`aes-gcm`、`flate2`、`pbkdf2`、`sha2`、`base64`、`rand` 用于同步和加密

## [0.1.3] - 2026-03-20

### 新增

- **日志系统** — 集成 `tauri-plugin-log` 实现 Rust 后端和 JavaScript 前端的统一运行时日志记录；日志同时写入文件（`LogDir`）、标准输出和 Webview 控制台；记录的关键事件包括：应用启动、窗口创建/销毁、快捷键注册、剪贴板监控生命周期、导入导出操作及错误信息
- **便签页面** — 新增专用 `sticky.html` + `sticky.js` 页面，通过 `WebviewUrl::App` 加载；便签窗口接收 `item_id` 并通过 Tauri 命令获取数据，与全屏窗口架构一致
- **浮动工具栏** — 复制和编辑按钮浮动在内容区域右上角，带背景模糊效果，编辑模式下自动隐藏
- **编辑模式指示条** — 进入编辑模式后 header 切换为绿色「✏️ 编辑中」指示条，配有明确的取消/保存按钮
- **未保存变更确认** — 取消编辑时如有未保存修改，弹出确认对话框
- **卡片 ID 标签** — 详情弹窗 header 左侧显示 `#短ID`（随机 hex 后缀），等宽字体标签样式
- **标签重复检测** — 输入已存在标签时，输入框红色边框抖动 + 显示"该标签已存在"提示
- **标签输入自动关闭** — 标签输入框失焦后 150ms 自动关闭（延迟避免点击冲突）

### 变更

- **编辑模式重构** — 从单按钮 toggle 重构为 `enterEditMode()` / `saveEdit()` / `cancelEdit()` 三函数架构
- **编辑按钮颜色区分** — 取消/保存使用绿色（`--success`）主题，与灰色工具按钮（全屏/便签/关闭）明确区分
- **移除底部 footer** — 复制/编辑按钮移至浮动工具栏；统计信息移至底部状态栏
- **标签区域重新设计** — 内联流式布局 + `+` 圆形按钮（虚线边框）；无标签时显示「+ 添加标签」，有标签时仅显示图标
- **语言选择器迁移** — 从标签区域移至状态栏右侧
- **Header 紧凑化** — 详情弹窗 header padding 从 `10px 16px` 缩减为 `6px 16px`
- **多页面样式统一** — 提取共享 CSS 类统一 modal、全屏、便签三个页面；便签内联样式改用 CSS 变量
- **全屏页面 header 精简** — 移除 header 中重复的统计信息（仅在底部状态栏显示）；固定 header 高度 44px
- **移除「关闭到托盘」设置** — 删除无效的 `closeToTray` 开关
- **编辑器高度行为** — 动态调整高度适应内容，输入时自动增长
- **工具栏按钮透明度** — 三级渐进透明度：默认 0.25 → 内容区域悬停 0.75 → 按钮悬停 1
- **窗口权限** — 在 capabilities 配置中添加 `sticky_*` 窗口权限

### 修复

- **全屏后应用失去响应（Windows）** — 将 `suppress_auto_hide` 从 `Mutex<bool>` 替换为 `AtomicUsize` 引用计数器，消除多窗口场景下的死锁
- **GitHub Actions Windows 构建失败** — 升级 `tauri-apps/tauri-action` 从 `@v0` 到 `@v0.5`
- **Windows 全屏页面空白** — 修复 HTML 内容生成中的 JavaScript 字符串转义问题
- **Windows 便签页面空白** — 替换为专用 `sticky.html` 页面，通过 Tauri 命令获取数据
- **内联编辑器视觉一致性** — 编辑模式现在与查看模式布局完全匹配
- **编辑器光标对齐** — 同步 textarea 和语法高亮层的 overflow 行为和 tab-size
- **全屏工具栏悬停失效** — 修复全屏页面工具栏按钮在 hover 时不显示的问题
- **便签水平滚动条** — 禁止水平滚动，所有内容自动换行适配窗口宽度
- **编辑模式下删除** — 现在会检查未保存的修改
- **国际化翻译缺失** — 补充 `editing`、`cancelEdit`、`saveEdit`、`addTagHint`、`tagExists` 的中英文翻译

### 安全

- **[严重] SQL 注入修复** — 在 `search_caches` 的 LIKE 条件中添加 `ESCAPE '\\'` 子句
- **XSS 消毒** — 全屏和便签页面的 HTML 注入现已消毒 `<script>` 标签

## [0.1.0] - 2026-03-03

### 新增

- **剪切板缓存** — 支持文本、图片（PNG / JPEG Data URL）、HTML 富文本
- **内容去重** — 文本精确匹配，图片 SHA-256 哈希去重
- **系统托盘** — 左键点击切换弹出窗口
- **全局快捷键** — `Alt+Shift+C`（可自定义），一键缓存剪切板
- **剪切板监听** — 可选 500ms 轮询自动缓存
- **搜索与标签** — 实时搜索、标签、置顶
- **详情弹窗** — 点击卡片查看完整内容
- **全屏查看** — 在独立窗口中全屏展示
- **缓存上限** — 可配置 10 ~ 999 条，自动淘汰
- **导入导出** — JSON 格式，导入自动去重
- **主题** — 跟随系统 / 浅色 / 深色
- **国际化** — 中英双语，即时切换
- **开机自启** — 可选开机启动
- **系统通知** — 可配置缓存事件通知
- **SQLite 存储** — 本地数据库，WAL 模式
- **跨平台** — macOS、Windows、Linux
- **隐私** — 数据本地存储
