# 更新日志

本文档记录此项目的所有重要变更。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.2.1] - 2026-03-26

### 新增

- **CodeMirror 6 语法高亮** — 使用 CodeMirror 6 替代 highlight.js，支持 30 种语言，采用 GitHub 风格亮色/暗色配色方案
- **CM6 内联编辑器** — 弹窗和全屏编辑模式使用完整的 CodeMirror 6 编辑器，支持行号、括号匹配、代码折叠、撤销/重做、搜索
- **CM6 按需加载** — CM6 bundle（~1 MB）仅在首次使用时动态加载，保持弹窗打开即时响应
- **回收站自动清理** — 过期回收站项目（>30 天）通过 `chrome.alarms` 每 6 小时自动清理

### 变更

- **图片同步逻辑** — "同步图片"开关仅控制上传；云端图片始终会被拉取，无论开关状态
- **主题感知高亮** — 语法高亮在切换亮色/暗色主题时自动适配

### 移除

- **highlight.js** — 已被 CodeMirror 6 替代

## [0.2.0] - 2026-03-23

### 新增

- **云同步** — 通过 GitHub Gist 跨设备同步剪贴板数据；使用细粒度 PAT（Gists 读写权限）连接
- **同步加密** — 所有云端数据均使用 AES-256-GCM + gzip 压缩加密；用户可设置可选的同步密码以增强安全性
- **同步密码管理** — 支持设置、修改、移除同步加密密码，包含确认校验
- **自动同步** — 本地数据变更后自动推送（防抖），打开 Popup 时拉取远端更新（限流避免过度 API 调用）；可在设置中开关
- **后台定时同步** — 通过 `chrome.alarms` 实现 5 分钟后台同步周期
- **快速同步按钮** — 顶栏快捷按钮，一键手动同步，带状态指示（同步中 / 已连接 / 错误）
- **图片云同步** — 可选同步图片类剪贴板内容到 Gist，支持单张（5 MB）和总量（50 MB）配额限制
- **强制推送** — 同步密码不匹配时提供强制推送选项，用本地数据覆盖云端数据
- **跨设备去重** — 基于内容哈希（SHA-256）的去重机制，防止同步时产生跨设备重复记录
- **回收站** — 软删除，保留 30 天；支持恢复或永久删除；显示剩余天数倒计时
- **回收站批量操作** — "全部恢复"和"清空回收站"按钮
- **永久删除全部数据** — 设置中的危险操作，可永久清除所有数据（活跃 + 回收站）
- **共享模块** — 提取 `shared/` 目录，包含 `constants.js`、`messages.js`、`icons.js`、`dom-utils.js`、`fullscreen-controller.js`、`crypto.js`，供扩展和桌面端共用
- **模块化架构** — `popup.js` 拆分为独立模块：`card-renderer.js`、`modal-controller.js`、`trash-panel.js`、`sync-ui.js`、`settings-panel.js`
- **自适应时间刷新** — 卡片相对时间和同步"上次同步"时间根据数据年龄以自适应间隔自动刷新

### 变更

- **国际化架构** — 共享 `BASE_MESSAGES` + 平台特定 `EXT_MESSAGES`；`mergeMessages()` 函数实现组合式翻译
- **时间格式化** — 委托给共享 `dom-utils.js`，通过依赖注入 `t()` 函数
- **代码组织** — `popup.js` 从约 1200 行缩减至约 390 行；`fullscreen.js` 使用共享 `fullscreen-controller.js`
- **Service Worker** — 为 `chrome.action.openPopup()` 添加 `try/catch`；通过 `chrome.alarms` 实现定时同步
- **扩展清单** — 新增 `alarms` 权限和 `https://api.github.com/*` 的 `host_permissions`
- **存储层** — 新增回收站操作、同步数据转换、待删除/待恢复追踪及内容哈希计算

### 安全

- **加密云端存储** — 存储在 GitHub Gist 中的所有同步数据均始终加密，无论用户是否设置密码

## [0.1.3] - 2026-03-20

### 新增

- **全屏页面** — 在新标签页中全屏展示缓存内容，支持文本、代码（语法高亮）、图片和 HTML 富文本
- **全屏内联编辑** — 在全屏页面直接编辑文本，实时语法高亮预览、自动增长输入框、同步滚动
- **浮动工具栏** — 复制和编辑按钮浮动在内容区域右上角，带背景模糊效果；三级渐进透明度
- **编辑模式指示条** — 进入编辑模式后 header 切换为绿色「✏️ 编辑中」指示条
- **未保存变更确认** — 取消编辑时如有未保存修改，弹出确认对话框
- **卡片 ID 标签** — 详情弹窗 header 显示 `#短ID`
- **标签重复检测** — 输入已存在标签时，输入框红色边框抖动 + 显示提示
- **标签输入自动关闭** — 标签输入框失焦后 150ms 自动关闭
- **常量模块** — 提取所有魔法数字和配置值到 `constants.js`

### 变更

- **编辑模式重构** — 从单按钮 toggle 重构为三函数架构
- **移除底部 footer** — 复制/编辑按钮移至浮动工具栏；统计信息移至底部状态栏
- **标签区域重新设计** — 内联流式布局 + `+` 圆形按钮
- **语言选择器迁移** — 从标签区域移至状态栏右侧
- **工具栏按钮透明度** — 三级渐进透明度
- **构建脚本** — 将 `fullscreen/` 目录加入构建拷贝列表

### 安全

- **[严重] SQL 注入修复** — 在搜索查询中转义 LIKE 特殊字符
- **[严重] XSS 防护** — 为 HTML 内容渲染添加 DOMPurify 清理机制

## [0.1.2] - 2026-03-10

### 新增

- **语法高亮** — 代码块使用 highlight.js 渲染，支持 30 种语言
- **内容编辑** — 在详情弹窗中直接编辑文本内容
- **语言选择器** — 为每条缓存选择语法高亮语言
- **详情弹窗重构** — 顶部显示元信息，操作按钮移至顶栏
- **设置页 About 区块** — 显示版本信息和 GitHub 链接
- **右键菜单** — 扩展图标右键菜单增加"设置"入口

### 修复

- **语法高亮不生效** — 构建脚本遗漏 `vendor/` 目录

### 变更

- **右键菜单精简** — 移除"缓存剪切板"和"打开 ClipStash"菜单项
- **标签展示** — 超长时截断并显示 tooltip
- **卡片代码预览** — 代码类型卡片显示语法高亮预览及语言标识
- **导入导出** — 数据中包含 `language` 字段

## [0.1.0] - 2026-03-03

### 新增

- **Popup 管理面板** — 点击插件图标打开
- **缓存剪切板按钮** — 一键缓存，支持成功、重复、空三种反馈
- **剪切板缓存** — 支持文本、图片、HTML 富文本
- **内容去重** — 相同内容不重复缓存
- **快捷键** — `Alt+Shift+C` 直接缓存剪切板
- **缓存列表** — 缩略展示、相对时间、字符数统计
- **快捷复制** — 一键复制，显示"已复制 ✓"
- **全屏查看** — 模态弹窗 + 新标签页全屏展示
- **删除** — 单条删除（二次确认）、一键清空
- **缓存上限** — 可配置 10 ~ 999
- **标签系统** — 为每条缓存添加/移除标签
- **搜索过滤** — 实时搜索，快捷键聚焦
- **滚动加载** — 默认 12 条，滚动到底自动加载
- **统计信息** — 缓存数/上限、匹配数、已占用空间
- **置顶** — 常用缓存置顶，黄色左边框标识
- **导入导出** — JSON 格式，导入自动去重
- **暗色主题** — 跟随系统 / 浅色 / 深色
- **国际化** — 中英双语，即时切换
- **快捷键** — 默认 `Alt+Shift+C`，可在 `chrome://extensions/shortcuts` 自定义
- **Manifest V3** — 支持 Chrome 104+
- **零依赖** — 纯前端实现，零运行时依赖
